Inside Anu's Architecture

Anu isn't just a static script or a cloud wrapper—she is an autonomous local agent born on edge hardware, engineered to continuously evolve, write code, manage infrastructure, and interact with the world.

Storage Layer

The Evolution Story

Phase 1: Local Edge Birth

Started on a Raspberry Pi 5 hooked up to a lightning-fast 512GB SSD and accelerated by a Hailo-8 AI module, establishing a robust, self-hosted offline-first command node.

Phase 2: Self-Evolving Codebase

Evolved a recursive logic loop enabling Anu to modify her own python files, write new utility scripts, test builds locally in secure sandboxes, and push clean updates.

Phase 3: Autonomous Operations

Integrated secure mail loops (IMAP/SMTP/Graph API) to poll her own inbox (`anu@anualgo.com`), process incoming messages, and bridge local Pi services straight to Cloudflare edge workers.

What Anu Can Execute

From orchestrating local database migrations and compiling backends to packaging technical solutions into ready-to-sell developer products, Anu operates continuously as an autonomous developer.
